# Close & Distant

**A critical text-as-data lab: what computation reveals, and misses, about human and machine writing.**

Close & Distant is an open teaching and research tool for transparent text analysis. It compares argumentative essays by English language learners with essays generated by a large language model, using measures that can be checked by hand, and pairs every computational step with close reading.

## What's in the site

| Section | What it does |
|---|---|
| **Compare** | Nine interpretable style measures (lexical diversity, word length, lexical sophistication, sentence length and variation, hedges, boosters, connectives, self-mention) plotted text by text for any two groups, plus keyness with concordance lines. Use the built-in essays, or load two sets of your own texts (.txt files, a CSV with a `text` column, or pasted text) and download the measures as CSV. |
| **Why detection fails** | A deliberately simple feature-based "AI detector". It catches 100% of default model output and flags no learners, until one prompt instruction ("write as a 10th-grade student") drops detection to 0%. Catching those essays wrongly flags 82% of learners. |
| **Lab 1** | Concordance and frequency on Austen's *Persuasion* and the essay corpora. |
| **Lab 2** | Keyness (log-likelihood, Log Ratio) and collocation (logDice, MI). |
| **Lab 3** | Authorship attribution with Burrows' Delta on nine public-domain books. At 100 most frequent words, 69 of 69 passages have a nearest neighbour by the same author. |
| **Lab 4** | Critical reading of an AI summary of Wentworth's letter in *Persuasion*: separating what the text says from what is said about it. |
| **Teach with it** | Ready-to-run session plans: a 60-minute academic integrity workshop, two digital humanities tutorials, a writing class and a research methods seminar. |

Everything runs in the browser. No text a user pastes or loads from a file is sent anywhere.

## Data

| Corpus | Source | Licence |
|---|---|---|
| 60 learner essays, two prompts, stratified by proficiency | ELLIPSE corpus (Crossley et al., 2023) | CC BY 4.0 |
| 24 model essays, same prompts, four documented instructions | Generated by Claude Opus 5.5 (Anthropic), 11 Nov 2026 | Released with this repository |
| Nine novels, 69 passages of 5,000 words | Project Gutenberg selection distributed with NLTK | Public domain |
| 2,000 most frequent English words | wordfreq (Speer, 2022) | CC BY-SA 4.0 |

The model essays are in `data/src/llm_essays.txt` with their instructions. `scripts/prepare_data.py` rebuilds every file in `web/public/data/` from the original ELLIPSE CSV and the NLTK Gutenberg folder.

## Reproducibility

- `analysis/features.py`: Python reference implementation of every measure.
- `web/src/lib/text.ts`: the browser implementation, mirroring the Python function by function.
- `tests/compare_outputs.py`: checks that both give the same numbers (84 essay profiles, keyness, the 69 × 69 Delta matrix, collocates). Current status: **all match**.
- `notebooks/`: one executed notebook per part of the site.

```bash
# Python side
pip install -r requirements.txt
python -I tests/compare_outputs.py      # needs Node and `npm install` in web/
python scripts/build_notebooks.py       # regenerates and executes the notebooks

# Website
cd web && npm install && npm run dev
```

## Deploying

The site is a static Vite + React build. On Vercel, import the repository and keep the defaults: `vercel.json` builds `web/` and serves `web/dist`.

## Limitations

- Small corpora, chosen so that every text can be read: 60 learner essays and 24 model essays on two prompts.
- One model, one session. Results do not describe language models in general.
- Learners are US secondary-school English language learners. The patterns may not hold for university writers or other populations.
- The detector is fitted and tested on the same essays. It is a teaching device, not a tool.
